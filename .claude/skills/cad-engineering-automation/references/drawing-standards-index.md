# Drawing standards index

> Titles/scopes only, from general knowledge. The standards themselves are
> copyrighted and are **not** reproduced here. Verify edition/year before
> citing a clause.

## ISO
| Standard | Scope |
|---|---|
| ISO 128 (series) | Technical product documentation - general principles of representation (lines, views, sections) |
| ISO 129-1 | Presentation of dimensions and tolerances |
| ISO 5456-2 | Orthographic projection (first/third angle, projection symbol) |
| ISO 5455 | Scales |
| ISO 5457 | Sheet sizes and layout of drawing sheets |
| ISO 216 | Paper sizes (A-series) |
| ISO 7200 | Title block data fields |
| ISO 2768-1/-2 | General tolerances (only if user specifies) |
| ISO 1101 | Geometrical tolerancing (GD&T) (only if user specifies) |
| ISO 5459 | Datums and datum systems (only if user specifies) |
| ISO 21920-1 (supersedes ISO 1302 indication) | Surface texture indication (only if user specifies) |
| ISO 6410 | Representation of screw threads |
| ISO 3098 | Lettering |

## ASME
| Standard | Scope |
|---|---|
| ASME Y14.5 | Dimensioning and tolerancing |
| ASME Y14.3 | Orthographic and pictorial views |
| ASME Y14.100 | Engineering drawing practices |
| ASME Y14.1 | Drawing sheet size and format |
| ASME Y14.2 | Line conventions and lettering |
| ASME Y14.6 | Screw thread representation |

Items marked "only if user specifies" are manufacturing information the product
must never invent.
