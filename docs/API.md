# HTTP API (v0.2)

Base: `/api`. Errors are `application/problem+json` with a stable `code`.
Interactive docs: `GET /docs` (OpenAPI generated by FastAPI).

| Method & path | Description |
|---|---|
| `GET /api/health` | liveness |
| `POST /api/models/upload` | multipart `file`; `.step/.stp/.stl`; 201 → `ModelOut` |
| `GET /api/models/{id}` | model metadata and status (`UPLOADED/ANALYZING/ANALYZED/FAILED`) |
| `POST /api/models/{id}/analyze` | 202 → `{job_id, job}`; idempotent while a job is running |
| `GET /api/models/{id}/geometry` | GeometryIR JSON |
| `GET /api/models/{id}/preview-mesh` | 3D preview mesh |
| `GET /api/jobs/{id}` | `{kind, state, progress 0-100, message, error{code,message}}` |
| `GET /api/drawings/defaults` | default `DrawingSettings` + option lists |
| `POST /api/drawings/generate` | body `{model_id, settings: DrawingSettings}` → 202 `{drawing_id, job_id, job}` |
| `POST /api/drawings/annotation-targets` | body `{model_id, settings}` → dimensions that will be placed, planar faces and features that annotations can reference, plus a datum-scheme suggestion (`datum_suggestion`, `datum_cautions`; not used by the UI - the planner applies the default scheme itself, see `default_gdt`), `rule_set` and `roles` (functional roles; `source=INFERRED` ones are assumptions to confirm / override in `feature_roles`) |
| `GET /api/drawings/{id}` | settings, QA report, pass/fail, scale, generator, available downloads, `compliance` (rule-set compliance report), `released`, `released_at` |
| `POST /api/drawings/{id}/release` | release for manufacture: 200 → `DrawingOut` with `released=true`; 409 `RELEASE_BLOCKED` while QA failed or a hard blocker fails (the detail lists them); 409 `JOB_NOT_COMPLETE` before generation |
| `GET /api/drawings/{id}/plan` | the deterministic DrawingPlan |
| `POST /api/drawings/{id}/validate` | re-run deterministic QA on the stored drawing → `QaReport` |
| `POST /api/drawings/{id}/regenerate` | body `{settings?}` → new drawing job (same model) |
| `GET /api/jobs/{id}/preview` | PNG of the sheet (also for QA-rejected drafts) |
| `GET /api/jobs/{id}/download/{pdf,dxf,svg}` | exports (409 `QA_FAILED` if QA blocked them) |
| `GET /api/jobs/{id}/download/{dwg,slddrw}` | 501 `FORMAT_REQUIRES_SOLIDWORKS` (never faked) |

`drawing_id` is the id of the drawing job.

## Job states
Analysis: `QUEUED → ANALYZING → COMPLETED | FAILED`.
Drawing: `QUEUED → PLANNING → GENERATING → VALIDATING → EXPORTING → COMPLETED | FAILED`,
with messages such as "Projecting views (iteration 1, scale 1:1)".

## Error codes
Upload: `UNSUPPORTED_FILE_TYPE`, `INVALID_CAD_CONTENT`, `EXTENSION_MISMATCH`, `FILE_TOO_LARGE`.
Resources: `NOT_FOUND`, `MODEL_NOT_ANALYZED`, `STL_NOT_SUPPORTED`, `NOT_A_DRAWING_JOB`, `JOB_NOT_COMPLETE`,
`QA_FAILED`, `FORMAT_REQUIRES_SOLIDWORKS`, `PMI_INVALID` (422: an annotation or a role override does not
match the part), `RELEASE_BLOCKED` (409).
Job errors: `STEP_READ_FAILED`, `STEP_NO_GEOMETRY`, `STL_READ_FAILED`, `LAYOUT_FAILED`, `QA_FAILED`,
`JOB_TIMEOUT`, `JOB_KILLED`, `JOB_CRASHED`, `GEOMETRY_ENGINE_UNAVAILABLE`, `DRAWING_ENGINE_UNAVAILABLE`,
`ANALYSIS_FAILED`, `DRAWING_FAILED`.

## DrawingSettings (request body)
`drawing_kind` (GEOMETRY; MANUFACTURING requires supplied material + general tolerance),
`drawing_standard` (ISO/ASME), `projection_method` (FIRST_ANGLE/THIRD_ANGLE),
`sheet {size A0-A4, orientation, scale (AUTO or a scale from options.scale), pictorial_scale, scale_system ISO_5455/INTERMEDIATE}`, `view_frame` (Z_UP / Y_UP = SolidWorks frame),
`view_selection` (default RULES: the rule set picks the fewest of `projected_views` and adds the
pictorial `primary_view` only when an isometric trigger fires; MANUAL: exactly as chosen),
`feature_roles` (user-set / confirmed functional roles `{target, role}`),
`primary_view` (default ISOMETRIC), `projected_views` (default FRONT, TOP, RIGHT),
`orthographic_display_style`, `dimensions {overall, feature, holes, radii, diameters, angles,
depths, decimal_places}`, `annotations {center_marks, centerlines, hole_callouts}`,
`title_block` (title, drawing/part number, revision, company, weight, quantity, sign-off names and
dates), `engineering_information`, `pictorial_style` (default SHADED_WITH_EDGES), and
`default_gdt` (default true: the rule set's defaults - ISO 2768-mK general tolerance, Ra 3.2 default finish,
default datums + GD&T and the role treatments - when no datums / frames are supplied), `general_notes` (default notes, on, `style` CONCISE/FULL: process, general geometric tolerance, edge break, masked
surfaces, thread class, process sequence, model revision, marking), `manufacturing` (datums, GD&T frames, tolerances, threads, inspection dimensions, basic (TED) dimensions, surface-finish
marks, feature notes, sheet notes, revisions, deburr flag — see DRAWING_ENGINE.md). JSON Schema:
`packages/drawing-schema/schema/drawing-settings.schema.json`.

## Preview mesh format
```json
{ "format": "cad-drawing-ai/preview-mesh@1", "units": "mm",
  "positions": [x,y,z,...], "indices": [i,j,k,...],
  "groups": [{"face_id": "FACE-…", "start": 0, "count": 96}],
  "edges": [{"edge_id": "EDGE-…", "points": [x,y,z,...]}] }
```
