# HTTP API (v0.1, milestone 1)

Base: `/api`. Errors are `application/problem+json` with a stable `code`.
Interactive docs: `GET /docs` (OpenAPI generated by FastAPI).

| Method & path | Status | Description |
|---|---|---|
| `GET /api/health` | ✅ | liveness + `solidworks_mode` |
| `POST /api/models/upload` | ✅ | multipart `file`; `.step/.stp/.stl`; 201 → `ModelOut` |
| `GET /api/models/{id}` | ✅ | model metadata, status (`UPLOADED/ANALYZING/ANALYZED/FAILED`) |
| `POST /api/models/{id}/analyze` | ✅ | 202 → `{job_id, job}`; idempotent while a job is running |
| `GET /api/models/{id}/geometry` | ✅ | GeometryIR JSON (409 `MODEL_NOT_ANALYZED` before analysis) |
| `GET /api/models/{id}/preview-mesh` | ✅ | preview mesh (`cad-drawing-ai/preview-mesh@1`) |
| `GET /api/jobs/{id}` | ✅ | `{state, progress 0-100, message, error{code,message}}` |
| `GET /api/drawings/defaults` | ✅ | default DrawingPlan + option lists for the settings UI |
| `POST /api/drawings/generate` | ⛔ 501 | planned (M2-M7) |
| `GET /api/jobs/{id}/preview` | ⛔ 409/501 | drawing jobs only; planned |
| `GET /api/jobs/{id}/download/{dwg,pdf,dxf,slddrw}` | ⛔ 409/501 | drawing jobs only; planned |
| `POST /api/drawings/{id}/validate` | ⛔ 501 | planned (QA milestone) |
| `POST /api/drawings/{id}/regenerate` | ⛔ 501 | planned |

Design changes vs. the initial sketch: `GET /api/models/{id}` added.
`geometry` and `preview-mesh` are separate resources, so the viewer can load
without parsing the full IR. `defaults` exposes the schema-backed options, so
the UI never hard-codes them.

## Job states
`QUEUED → ANALYZING → (PLANNING → GENERATING → VALIDATING → EXPORTING) → COMPLETED | FAILED`.
Analysis jobs use `QUEUED → ANALYZING → COMPLETED|FAILED` with stage messages
("Importing STEP", "Classifying edges", "Recognizing features", ...).

## Error codes (upload/analysis)
`UNSUPPORTED_FILE_TYPE`, `INVALID_CAD_CONTENT`, `EXTENSION_MISMATCH`, `FILE_TOO_LARGE`,
`NOT_FOUND`, `MODEL_NOT_ANALYZED`, `NOT_A_DRAWING_JOB`, `NOT_IMPLEMENTED`;
job errors: `STEP_READ_FAILED`, `STEP_NO_GEOMETRY`, `STL_READ_FAILED`, `ANALYSIS_TIMEOUT`,
`ANALYSIS_KILLED`, `ANALYSIS_CRASHED`, `GEOMETRY_ENGINE_UNAVAILABLE`, `ANALYSIS_FAILED`.

## Preview mesh format
```json
{ "format": "cad-drawing-ai/preview-mesh@1", "units": "mm",
  "positions": [x,y,z,...], "indices": [i,j,k,...],
  "groups": [{"face_id": "FACE-…", "start": 0, "count": 96}],
  "edges": [{"edge_id": "EDGE-…", "points": [x,y,z,...]}] }
```
`groups` map index ranges to GeometryIR face ids (empty for STL).
