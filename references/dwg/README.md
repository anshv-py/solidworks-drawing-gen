# DWG / DXF

| Option | Licence | Fit |
|---|---|---|
| SolidWorks export (SaveAs3 → .dwg/.dxf) | SolidWorks licence | **primary**: authoritative drawing engine produces DWG/DXF |
| Autodesk DXF Reference | public documentation | format reference for validating DXF output |
| ezdxf (Python) | MIT | reading/validating DXF on Linux (QA, preview) |
| ODA Drawings SDK (Teigha) | commercial membership | only if DWG must be read/written outside SolidWorks |
| LibreDWG | GPL-3.0 | **not** compatible with a proprietary product - avoid |
